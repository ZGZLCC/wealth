# 财富计算器

一个零依赖的静态页面：按月推演「工资、生活费、育儿、房贷、自己加的专项」，算出工作这些年最后能攒下多少钱，以及这笔钱在不上班之后还能撑多少年。所有计算都在浏览器里完成，不联网、不上传任何数据。

## 在线使用

**直接打开：<https://zgzlcc.github.io/Wealth/>**

不用安装任何东西。填的数字只存在你自己浏览器的 localStorage 里（键名 `wealth-calc-v1`），不会上传到任何地方；换设备、换浏览器不会带走。

## 做了什么

- **生活开支**卡：单人还是夫妻、人均月消费、年收益率、通货膨胀率。
- **专项支出**卡：育儿、房子、健康三块，外加自己加的任意专项。
  - 育儿：每孩总成本，按 22 年摊到每月；孩子数量可改，**每个孩子单独填开始年份**。
  - 房子：首付 + 首付年份，房贷月供 + 月供开始年份 + 房贷年数；全款就把月供填 0。
  - 健康：工作结束时预留一笔，用于医疗等方面。
  - 三块都能**移除**，移除后不参与计算；底部的「＋ 育儿 / ＋ 房子 / ＋ 健康」可以把它们加回来，加回来是默认值。
  - 「＋ 新增专项支出」可以加自己的专项：名称、金额 + 年份、每月金额 + 月付开始年份 + 年数（默认全是 0），名字会写进结果说明里。
- **工资计算**卡：初始资金、年均工资、前期年数与年增长率、后期年数与年增长率（两段年数相加就是工作时长；增长率可以填负数表示降薪）。
- **两张结果卡**：
  - 工作 N 年后能攒下多少，扣掉各项之后的净额，以及育儿 / 房贷 / 专项的逐月扣款说明。
  - 这笔钱能撑多少年：收益跑得过通胀与花销时直接显示「永远」，否则给出具体年数。
- 主题三选一（跟随系统 / 浅色 / 深色），默认跟随系统。

## 计算方式

金额单位统一是「万元」，比率的单位是百分比数值（`4.5` 表示 4.5%）。核心是一个逐月推演的现金流模型：从初始资金出发，一个月一个月往后滚，直到工作时长结束。

**每个月的顺序**

```
余额 = 上月余额 × (1 + 月收益率)      ← 余额为负的月份不记收益
     + 当月工资
     − 当月生活费（按通胀逐年上涨）
     − 当月育儿
     − 当月房贷
     − 当月自定义专项
```

- **月收益率**按 `(1 + 年收益率)^(1/12) − 1` 精确换算，12 个月复利正好等于年收益率。
- **工资**：年均工资 ÷ 12；每走满一整年调一次，前 A 年乘前期增长率，之后 B 年乘后期增长率。增长率可以是负数，最多降到工资 0。
- **生活费**：人均月消费 × 人数（单人 1、夫妻 2），每年按 `(1 + 通胀)^第几年` 上调。这个数不含房贷与育儿。

**育儿怎么摊**

22 年（出生到大学毕业）按年龄分六段，每段一个相对权重，先归一化（权重和 23.8），所以摊完正好等于「每孩总成本 × 孩子数」，只是前少后多：

| 阶段 | 年数 | 权重 |
| --- | --- | --- |
| 0–2 岁 | 3 | 0.6 |
| 3–5 岁（幼儿园） | 3 | 1.0 |
| 6–11 岁（小学） | 6 | 0.9 |
| 12–14 岁（初中） | 3 | 1.1 |
| 15–17 岁（高中） | 3 | 1.3 |
| 18–21 岁（大学） | 4 | 1.6 |

每个孩子从自己的开始年份起摊 264 个月；同时有两个孩子就是两段独立的窗口。

**房子与自定义专项**

- 房子总成本 = 首付 + 月供 × 12 × 房贷年数（月供里含利息）。
- 自定义专项 = 一次性金额（在「年份」那一年付）+ 每月金额 × 12 × 年数（从「月付开始年份」那年算）。
- 两者的一次性那笔都是「某个月集中扣一次」，月付则按月扣。

**余额被打穿的时候**

只有一次性大额（首付、自定义专项的一次性金额）那个月允许把余额打成负数；其他月份凭空转负，说明这套收支撑不住，推演就地停下，并给出停下的月份与余额。

被打穿的这一段当作欠款继续往下跑：

- 欠款期间**不计收益**，每个月的结余全部拿去还，还清了余额才重新开始增值；
- 一个人可以被打穿好几次（比如第 2 年首付、第 10 年买车），**每一段都单独提示**：是哪笔支出、掉到多少、第几年回到正数；
- 到工作结束都没还清的那段会写「之后一直没回到正数」。

**两张结果卡的关系**

- 第一张卡的数字 = 工作结束时的余额 − 医疗预留。**未付完的育儿 / 房贷 / 专项不在这里一次扣掉**，只提示「另外还有多少要在工作结束后继续付」。
- 第二张卡拿这笔钱，从工作结束那个月接着往下推：没有工资了，生活费继续按通胀涨，没付完的育儿 / 房贷 / 专项按各自的日程继续按月扣，余额按同一个年收益率增值，看能撑多久（最多看 100 年，撑得住就写「永远」）。

**默认参数与结果**

夫妻、人均月消费 0.5 万、年收益率 4.5%、通胀 2%、1 个孩子（第 2 年开始，100 万）、首付 90 万（第 8 年）+ 月供 1.1 万 × 25 年、医疗预留 150 万、初始资金 0、年均工资 24 万（前 10 年每年涨 8%，接着 20 年每年涨 3%）。

工作 30 年结束手上 1,225.9 万，预留 150 万医疗后 **1,075.9 万**；第二张卡显示这笔钱「永远」花不完。

## 本地运行

不需要 `npm install`，也没有构建步骤：所有文件都是浏览器直接执行的原生 ES module。只是**不能直接双击 `index.html`**——`file://` 协议下浏览器会以 CORS 为由拦掉 `./src/app.js`，页面会白屏。所以起一个本地静态服务器就行。

### 方式一：仓库自带的服务器（推荐，需要 Node.js）

```bash
cd Wealth          # 进入项目根目录，也就是 index.html 所在的那层
node scripts/serve.mjs
```

终端会打印 `财富计算器：http://127.0.0.1:5182/`，浏览器打开这个地址即可。装了 npm 的话 `npm run dev` 是等价的（同样不用 `npm install`）。

- **换端口**：`PORT=8080 node scripts/serve.mjs`；Windows PowerShell 里写 `$env:PORT="8080"; node scripts/serve.mjs`
- **给同一局域网的手机 / 另一台电脑看**：`HOST=0.0.0.0 node scripts/serve.mjs`（PowerShell 用 `$env:HOST="0.0.0.0"; node scripts/serve.mjs`），然后访问 `http://<本机IP>:5182/`
- **停止**：终端里按 Ctrl+C

### 方式二：任意静态服务器

只要能把项目根目录当静态站点发出来就行，用你顺手的工具：

```bash
# Python 3
python -m http.server 5182

# 或者 Node 的 npx serve
npx serve -l 5182 .
```

同样打开 <http://127.0.0.1:5182/>。注意要在**项目根目录**（`index.html` 所在目录）执行，在子目录里起服务会 404。

### 打开后应该看到

标题「财富计算器」，从上到下依次是：生活开支卡、专项支出卡、工资计算卡、还能撑多少年卡。用默认参数就能出结果——工作 30 年结束手上 1,225.9 万，扣掉 150 万医疗预留后 **1,075.9 万**，第二张卡显示「永远」。

整个文件夹没有任何依赖和生成物，拷到别的机器上照样能跑。

### 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 页面白屏，控制台报 CORS 或 MIME type 错误 | 是双击 `index.html` 用 `file://` 打开的，改用上面的服务器 |
| 启动时报 `EADDRINUSE` / 端口被占用 | 换一个端口：`PORT=8081 node scripts/serve.mjs` |
| 改了文件页面没变 | 服务器响应带 `cache-control: no-store`，刷新即可；确认改的是 `src/` 下对应文件 |
| 想把数字清空回默认 | 页面底部「恢复默认值」；或清掉该站点的 localStorage（键 `wealth-calc-v1`） |
| 主题想固定成浅色 / 深色 | 右上角三选一，选择记在 `wealth-theme`，默认跟随系统 |
